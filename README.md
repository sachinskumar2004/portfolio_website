# Sachin S Kumar — Portfolio Website

A personal portfolio website built to showcase my work as a **UI/UX Designer**, **Graphic Designer**, and **Front-End Web Developer**.

🔗 **Live Site:** [sachinskumar.vercel.app](https://sachinskumar.vercel.app/)

## About

I'm a B.Tech Computer Science student passionate about transforming digital experiences through front-end development and design. This site brings together my education, skills, experience, and portfolio in one place.

## Sections

- **About** — A quick introduction and contact details
- **Education** — Academic background, from school to current B.Tech studies
- **Skills** — Visual breakdown of proficiency in tools like Adobe Photoshop, Figma, Alight Motion, HTML5, and CSS3
- **Experience** — Freelance and leadership roles, including UI/UX Lead and Design Lead at Mulearn (College of Engineering, Perumon)
- **Portfolio** — A gallery of web and graphic design work
- **Contact** — A working contact form plus direct phone/email details

## Built With

- HTML5
- CSS3
- JavaScript
- [Bootstrap 3](https://getbootstrap.com/)
- [Owl Carousel](https://owlcarousel2.github.io/OwlCarousel2/)
- [Font Awesome](https://fontawesome.com/)

## Getting Started

To run this locally:

```bash
git clone https://github.com/sachinskumar2004/portfolio_website.git
cd portfolio_website
```

Then simply open `index.html` in your browser — no build step required.

## Deployment

This site is deployed on [Vercel](https://vercel.com/) and auto-deploys from the `main` branch.
